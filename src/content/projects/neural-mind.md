## The Backstory

Every knowledge management app I tried felt the same — flat lists, folders, tags. But that's not how the brain works. Ideas connect to each other in webs, not hierarchies. I wanted to type a concept and watch the app figure out what it relates to, building a visual map of understanding in real time. That's NeuralMind.

## Key Features

- **ML-powered mind maps** — Type concepts and the app analyzes associations in real time, generating interactive node graphs
- **Visual knowledge graph** — Concepts appear as connected nodes with directional relationships, zoomable and explorable
- **Dark mode** — Full dark theme for comfortable use
- **8 languages** — English, Korean, Japanese, Chinese, Vietnamese, Turkish, German, French
- **Bulk node generation** — Import JSON data or use AI-assisted methods to create large concept maps quickly
- **Search & filter** — Find any concept across your entire knowledge graph instantly
- **Privacy-first** — No data collected, no data shared with third parties

## How It Works

The core interaction is simple: create a concept node, and the app uses machine learning to identify related concepts and suggest connections. As you build out nodes, the graph grows organically — revealing patterns and relationships you might not have noticed in a traditional note-taking app.

The graph view supports pinch-to-zoom, node dragging, and connection mode where you can manually link concepts. Each node can hold detailed descriptions, and the entire graph is searchable.
