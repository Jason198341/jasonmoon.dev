## Git = 게임 세이브 포인트

보스전 전에 세이브하잖아요? 죽으면 세이브 포인트에서 다시 시작.

Git이 딱 그겁니다. **코드의 세이브 포인트.**

"뭔가 바꿨는데 다 망가졌어" → Git이 있으면 3초 만에 되돌립니다.

## 4가지 개념. 이게 전부입니다.

### 1. Repository (저장소)
프로젝트 폴더입니다. Git한테 "이 폴더 추적해"라고 하면 저장소가 됩니다.

### 2. Commit (커밋)
세이브 포인트를 만드는 겁니다. "지금 잘 되니까 저장하자."

```bash
git add .
git commit -m "로그인 페이지 완성"
```

`-m` 뒤의 메시지가 세이브 파일 이름입니다. "로그인 페이지 완성", "버그 수정", "색상 변경" — 뭘 했는지 적으면 됩니다.

### 3. Push (푸시)
로컬 세이브를 **인터넷(GitHub)**에 업로드하는 것.

```bash
git push
```

왜? 두 가지 이유:
- **백업**: 노트북이 고장나도 코드는 살아남음
- **포트폴리오**: 다른 사람들이 내가 만든 걸 볼 수 있음

### 4. Pull (풀)
그 반대 — 인터넷에서 최신 코드를 **내 컴퓨터로** 다운로드.

```bash
git pull
```

## 실습: 제로에서 시작

### 1단계: Git 설치
[git-scm.com](https://git-scm.com) → 다운로드 → 기본 설정으로 설치.

### 2단계: GitHub 계정 만들기
[github.com](https://github.com) → 가입. 무료.

GitHub은 Git으로 관리하는 코드의 클라우드 저장소입니다. **개발자들의 인스타그램**이라고 생각하세요 — 만든 걸 보여주는 곳.

### 3단계: 첫 커밋

터미널에서:

```bash
git init                        # 이 폴더 추적 시작
git add .                       # 모든 파일을 세이브 목록에 추가
git commit -m "첫 번째 저장"      # 저장!
```

### 4단계: GitHub에 푸시

```bash
git remote add origin https://github.com/yourusername/yourproject.git
git push -u origin main
```

이거 외울 필요 없습니다. Claude Code한테 **"이거 GitHub에 올려줘"**라고 하면 알아서 다 해줍니다.

## Claude Code를 쓰면 더 쉽습니다

```
나: "GitHub에 다 올려줘"
Claude: (자동 커밋 → 푸시 → 끝)
나: "마지막 변경 취소해줘"
Claude: (이전 커밋으로 복원)
```

## 흔한 실수

**"git push가 안 돼!"**
→ 99%는 GitHub에 로그인이 안 된 겁니다. 한 번 인증하면 그 다음부터는 자동.

**"뭔가 꼬인 것 같아..."**
→ 당황하지 마세요. `git status`를 실행해서 상태를 확인하세요. 결과를 AI한테 보여주면 고쳐줍니다.

**이것만 기억하세요**: Git은 안전망입니다. 자주 커밋할수록 안전합니다.
