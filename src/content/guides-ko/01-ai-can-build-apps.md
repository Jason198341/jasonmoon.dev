## 잠깐, 이게 진짜 돼?

네. 진짜요.

이 사이트에 있는 모든 프로젝트 — SAT 학습 플랫폼, 4개 AI 에이전트가 분석하는 주식 도구, 유튜브 중독 차단기 — 전부 AI한테 말해서 만들었습니다. 부트캠프 다닌 게 아닙니다. 코딩 문제 풀기한 게 아닙니다. **"이거 만들어줘"** 하고 반복한 겁니다.

## 딱 3가지만 있으면 됩니다

1. **컴퓨터** — 윈도우든 맥이든 상관없음
2. **아이디어** — "이런 게 있었으면..." 이 정도면 충분
3. **AI 도구** — Claude Code, Cursor, 또는 GitHub Copilot

코딩 실력? 제로여도 됩니다. 진짜로.

## 어떻게 가능한 거야?

통역사 친구가 있다고 생각하세요. 여러분은 한국어로 말하고, 친구가 코드로 번역해줍니다.

```
나: "이메일이랑 비밀번호로 로그인하는 페이지 만들어줘"
AI: (코드를 작성)
나: "비밀번호는 8자 이상이어야 한다는 규칙 추가해줘"
AI: (코드를 수정)
```

이게 2025년 현실입니다.

## 설치할 것들

### 1단계: Node.js
Node.js는 자바스크립트를 브라우저 바깥에서 실행하는 엔진입니다. 현대 웹 개발의 기본 뼈대라고 보면 됩니다.

[nodejs.org](https://nodejs.org)에서 LTS 버전 다운로드 → 설치 → 끝.

### 2단계: VS Code
코드를 보고 편집하는 프로그램입니다. 메모장의 프로 버전이라고 생각하세요.

[code.visualstudio.com](https://code.visualstudio.com)에서 다운로드.

### 3단계: AI 도구 선택

| 도구 | 작동 방식 | 가격 |
|------|----------|------|
| **Claude Code** | 터미널에서 AI와 대화. 파일 생성, 명령 실행, 에러 수정을 직접 해줌 | 구독제 |
| **Cursor** | AI가 내장된 VS Code | 무료 플랜 있음 |
| **ChatGPT** | 코드 복사-붙여넣기 방식 | 무료 |

추천: **Claude Code**. 코드를 제안만 하는 게 아니라 — 파일을 만들고, 앱을 실행하고, 에러를 알아서 고칩니다. 여러분이 할 일이 최소화됩니다.

## 첫 프로젝트: 뭘 만들까?

**진짜 필요한 걸 만드세요.**

- 일정 관리 앱
- 지출 기록 앱
- 단어 암기 플래시카드
- 개인 일기 웹사이트

"그런 건 이미 있잖아." 맞아요. 하지만 **딱 내가 원하는 방식**으로 만들어진 건 없죠. 그래서 직접 만드는 겁니다.

## 겁먹지 마세요

코드가 터져도 컴퓨터가 폭발하지 않습니다. 최악의 경우: 빨간 에러 메시지가 화면에 뜹니다. 그걸 AI한테 복사해서 붙여넣으면 고쳐줍니다.

**실패해도 아무 일도 안 일어납니다.** 이게 코딩의 가장 좋은 점이에요.

다음: Git — 만든 것들을 안전하게 저장하고 관리하는 방법.
